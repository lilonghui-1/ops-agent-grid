1. 系统概述

1.1 架构总览

Ops-Agent-Grid 采用前后端分离 + Agent 智能体架构：

  • 后端 (Python/FastAPI)：提供 REST API、WebSocket 实时通信、Agent 编排引擎、定时调度
  • 前端 (Vue 3/Element Plus)：Web 管理界面，含仪表盘、服务器管理、日志检索、Web 终端、告警中心等
  • Agent 层：Coordinator 协调器 + 4 大 Specialist 专家 (SRE/网络/数据库/计算) + 事件调查器 + 审批评审器
  • 工具层：SSH 工具、数据库工具、K8s 工具、网络工具、拓扑工具、日志工具、通知工具等 20+ 工具
  • 通道层：Slack / 钉钉 / 企业微信 / Telegram / 飞书 统一消息路由

1.2 核心功能

模块功能
服务器巡检CPU/内存/磁盘/网络指标采集，阈值告警，支持 Linux + Windows
故障诊断AI 驱动的自动故障根因分析 (RCA)，事件时间线

Web 终端浏览器内 SSH 终端 (xterm.js + WebSocket)
告警管理阈值规则 + 日志关键词 + PromQL 规则，Alertmanager Webhook 兼容

2.4 SSH 免密配置

Ops-Agent 通过 SSH 连接目标服务器，需配置密钥认证：

# 1. 在部署服务器上生成密钥对
ssh-keygen -t rsa -b 4096 -f ~/.ssh/ops_agent_key -N ""

# 2. 将公钥分发到目标服务器
ssh-copy-id -i ~/.ssh/ops_agent_key.pub ops@192.168.1.10
ssh-copy-id -i ~/.ssh/ops_agent_key.pub ops@192.168.1.20

# 3. 验证免密登录
ssh -i ~/.ssh/ops_agent_key ops@192.168.1.10 "hostname"

# 4. 设置环境变量
export SSH_PRIVATE_KEY_PATH=~/.ssh/ops_agent_key
Windows 目标服务器需安装 OpenSSH Server 并配置密钥认证。参见 附录: Windows SSH 配置。

4. 日志平台部署 (Loki + Grafana)

Ops-Agent 支持对接 Grafana Loki 进行集中日志查询。以下为完整的 Loki + Promtail + Grafana 部署步骤。

4.1 Grafana Loki 安装

方式一：二进制安装 Linux

# 下载 Loki
wget https://github.com/grafana/loki/releases/download/v3.0.0/loki-linux-amd64.zip
unzip loki-linux-amd64.zip
mv loki-linux-amd64 /usr/local/bin/loki
chmod +x /usr/local/bin/loki

# 创建配置文件
mkdir -p /etc/loki /var/lib/loki

cat > /etc/loki/loki-config.yaml << 'EOF'
auth_enabled: false

server:
  http_listen_port: 3100
  grpc_listen_port: 9096

common:
  path_prefix: /var/lib/loki
  storage:
    filesystem:
      chunks_directory: /var/lib/loki/chunks
      rules_directory: /var/lib/loki/rules
  replication_factor: 1
  ring:
    kvstore:
      store: inmemory

schema_config:
  configs:
    - from: 2024-01-01
      store: tsdb
      object_store: filesystem
      schema: v13
      index:
        prefix: index_
        period: 24h

limits_config:
  retention_period: 30d
  max_query_length: 721h
  reject_old_samples: true
  reject_old_samples_max_age: 168h

analytics:
  reporting_enabled: false
EOF

# 启动 Loki
/usr/local/bin/loki -config.file=/etc/loki/loki-config.yaml &

方式二：Docker 安装

docker run -d --name loki \
  -p 3100:3100 \
  -v /etc/loki/loki-config.yaml:/etc/loki/loki-config.yaml \
  -v /var/lib/loki:/var/lib/loki \
  grafana/loki:3.0.0 \
  -config.file=/etc/loki/loki-config.yaml

4.2 Promtail 安装与配置

Promtail 负责采集目标服务器日志并推送到 Loki。

安装 Promtail

wget https://github.com/grafana/loki/releases/download/v3.0.0/promtail-linux-amd64.zip
unzip promtail-linux-amd64.zip
mv promtail-linux-amd64 /usr/local/bin/promtail
chmod +x /usr/local/bin/promtail

配置 Promtail

mkdir -p /etc/promtail

cat > /etc/promtail/promtail-config.yaml << 'EOF'
server:
  http_listen_port: 9080
  grpc_listen_port: 0

positions:
  filename: /var/lib/promtail/positions.yaml

clients:
  - url: http://localhost:3100/loki/api/v1/push

scrape_configs:
  # 系统日志
  - job_name: system
    static_configs:
      - targets:
          - localhost
        labels:
          job: varlogs
          host: localhost
          __path__: /var/log/*log

  # Nginx 日志
  - job_name: nginx
    static_configs:
      - targets:
          - localhost
        labels:
          job: nginx
          host: localhost
          __path__: /var/log/nginx/*.log

  # 应用日志
  - job_name: application
    static_configs:
      - targets:
          - localhost
        labels:
          job: application
          host: localhost
          __path__: /opt/app/logs/*.log

  # Ops-Agent 自身日志
  - job_name: ops-agent
    static_configs:
      - targets:
          - localhost
        labels:
          job: ops-agent
          host: localhost
          __path__: /var/log/ops-agent/*.log
EOF

# 创建数据目录
mkdir -p /var/lib/promtail

# 启动 Promtail
/usr/local/bin/promtail -config.file=/etc/promtail/promtail-config.yaml &

远程服务器日志采集

在每台目标服务器上安装 Promtail 并指向中心 Loki：

# 修改 clients URL 为 Loki 服务器地址
clients:
  - url: http://loki-server:3100/loki/api/v1/push

Systemd 服务（推荐）

# /etc/systemd/system/promtail.service
[Unit]
Description=Promtail Log Agent
After=network.target

[Service]
ExecStart=/usr/local/bin/promtail -config.file=/etc/promtail/promtail-config.yaml
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target

# 启动
systemctl daemon-reload
systemctl enable --now promtail

8.2 前端启动

开发模式

cd web

生产模式（Nginx 托管）

# 构建前端
cd web
npm run build

# 配置 Nginx
cat > /etc/nginx/conf.d/ops-agent.conf << 'EOF'
server {
    listen 80;
    server_name ops-agent.your-domain.com;

    # 前端静态资源
    root /path/to/ops-agent-grid/web/dist;
    index index.html;

    # SPA 路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket 代理
    location /ws/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
    }
}
EOF

nginx -t && systemctl reload nginx

9. 部署验证

  1. 后端健康检查：curl http://localhost:8000/api/health → 返回 {"status":"ok"}
  2. 前端访问：浏览器打开 http://localhost:5173（开发）或 http://your-server（生产）
  3. 登录验证：使用 admin / admin123 登录，应跳转到仪表盘
  4. 服务器连接：在「服务器管理」页面查看服务器是否在线
  5. 日志检索：在「日志查询」页面输入查询条件，验证 Loki 连接
  6. Web 终端：在「Web 终端」页面选择服务器并连接，验证 SSH
  7. 告警 Webhook：curl -X POST http://localhost:8000/api/alerts/webhook -H "Authorization: Bearer <token>" -d '{"alerts":[]}'

10. 常见问题

Q: Python 2.7 环境下无法运行？

Ops-Agent 要求 Python 3.9+。请使用 python3 命令或在虚拟环境中运行。

Q: 前端页面显示 Network Error？

检查后端是否已启动，以及 Nginx 反向代理配置中 /api/ 路径是否正确代理到后端 8000 端口。

Q: SSH 连接超时？

  1. 确认目标服务器 SSH 端口 22（或自定义端口）可达
  2. 确认密钥文件路径正确：echo $SSH_PRIVATE_KEY_PATH
  3. 手动验证：ssh -i ~/.ssh/ops_agent_key ops@target-ip
  4. Windows 目标服务器需安装 OpenSSH Server

Q: Loki 查询无数据？

  1. 检查 Promtail 是否在运行：systemctl status promtail
  2. 检查 Promtail 配置中的 __path__ 是否匹配日志文件路径
  3. 在 Grafana Explore 中执行 {job=""} 查看所有标签
  4. 检查 Loki clients URL 是否正确

Q: 数据库连接失败？

  1. 确认数据库服务正常运行
  2. 确认对应驱动已安装：pip list | grep oracledb
  3. Oracle 需检查 Service Name 或 SID 是否正确
  4. 达梦需确认 DM_HOME 和 LD_LIBRARY_PATH 已设置

Q: AI 对话无响应？

  1. 检查 OPENAI_API_KEY 等环境变量是否设置
  2. 检查 config.yaml 中 llm_models 配置
  3. 查看后端日志：journalctl -u ops-agent -f
